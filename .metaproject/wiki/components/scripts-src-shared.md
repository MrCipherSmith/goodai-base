# Module scripts/src/shared

## Overview

`scripts/src/shared` is a utility module containing reusable helper functions shared across multiple script modules in the project. It provides filesystem operations, argument parsing, checksum computation, and metadata handling (agent markdown, frontmatter, keywords). By centralizing these cross-cutting concerns, the module reduces code duplication and ensures consistent behavior.

## How it works

The module is organized as six independent source files, each exporting a small, focused set of functions. There are zero internal dependencies between these files, meaning each utility can be imported individually without pulling in unrelated code. The files fall into these logical groups:

- **Filesystem utilities** (`fs-utils.ts`): functions for ensuring directories exist, copying files, reading/writing text files, checking file existence, and expanding the tilde (`~`) path.
- **Argument parsing** (`args.ts`): types and functions to parse command-line arguments (`ParsedArgs`, `parseArgs`, `getOption`, `getFlag`).
- **Checksum** (`checksum.ts`): computation of file or data checksums.
- **Agent markdown** (`agents-md.ts`): utilities for working with agent-related Markdown content.
- **Frontmatter** (`frontmatter.ts`): extraction and manipulation of YAML/TOML-like frontmatter from text files.
- **Keywords** (`keywords.ts`): extraction or processing of keywords.

Consumers import only the specific file they need. The module’s public API consists of ten symbols: `ensureDir`, `copyFile`, `readTextFile`, `writeTextFile`, `fileExists`, `expandHome`, `ParsedArgs`, `parseArgs`, `getOption`, `getFlag`.

## Key concepts

- **Filesystem helpers** – wrappers around Node.js `fs` and `path` modules that also expand `~` to the user’s home directory.  
- **Argument parser** – a simple parser that converts an array of strings (typically `process.argv`) into a structured `ParsedArgs` object, supporting options and flags.  
- **Checksum** – a utility for generating cryptographic hashes (e.g., SHA256) of files or strings.  
- **Metadata processing** – functions for reading and writing frontmatter blocks and handling agent-specific Markdown content.

These concepts are independent; no single file depends on another within the module.

## Main flows

1. **Reading a file with home-directory expansion** – A script calls `readTextFile(expandHome('~/data/config.yml'))`. The `expandHome` call resolves the path, then `readTextFile` returns the file contents.  
2. **Parsing CLI arguments** – A script invokes `parseArgs(process.argv.slice(2))` to get a `ParsedArgs` object, then uses `getOption('--output')` to retrieve a specific option value or `getFlag('--verbose')` to check for a boolean flag.  
3. **Copying a file** – A build step uses `copyFile(sourcePath, destPath)` to duplicate a file, with `ensureDir` called first to guarantee the destination directory exists.
