# PRD: Phase 5 — Двухэтапное code review в строгом порядке

## Цель

Разделить code review на два последовательных этапа: сначала соответствие спецификации, затем качество кода. Никогда одновременно.

## Проблема

Текущий `code-review` скилл смешивает два разных вопроса:
1. "Сделано ли то, что просили?" (соответствие спецификации)
2. "Хорошо ли это сделано?" (качество кода)

Смешение приводит к тому, что:
- Аргументы о качестве кода маскируют scope drift ("зато как красиво написано")
- Аргументы о соответствии спецификации маскируют плохой код ("зато делает что просили")
- Оба аспекта получают поверхностное внимание

## Решение

Ввести обязательный двухэтапный процесс:

### Этап 1: Spec Compliance Review
**Вопрос**: Сделано ли именно то, что описано в задаче/спецификации?

Checklist:
- [ ] Все acceptance criteria выполнены?
- [ ] Ничего лишнего не добавлено сверх задачи?
- [ ] Ничего из задачи не пропущено?
- [ ] Поведение соответствует описанному в задаче?

**Gate**: Пока Spec Compliance не пройден → Этап 2 не начинается.

### Этап 2: Code Quality Review
**Вопрос**: Хорошо ли реализовано то, что сделано?

Checklist:
- [ ] Логика корректна?
- [ ] Нет security уязвимостей?
- [ ] Производительность приемлема?
- [ ] Код читаем и поддерживаем?
- [ ] Тесты покрывают ключевые сценарии?

## Скоп изменений

1. `skills/code-review/SKILL.md` — переструктурировать в 2 последовательных этапа
2. `skills/code-ai-review/SKILL.md` — то же самое
3. `skills/code-boss-review/SKILL.md` — то же самое
4. `skills/code-style-review/SKILL.md` — уточнить что это только Этап 2

## Iron Law

**SPEC COMPLIANCE REVIEW ВСЕГДА ИДЁТ ПЕРВЫМ. ЭТАП 2 НЕ НАЧИНАЕТСЯ ПОКА ЭТАП 1 НЕ ПРОЙДЕН.**

## Acceptance Criteria

- [ ] Все review скиллы имеют явно разделённые Этап 1 и Этап 2
- [ ] Gate между этапами явно описан и включает условие блокировки
- [ ] Iron Law присутствует в каждом review скилле
- [ ] Оба этапа имеют конкретные checklists, а не абстрактные описания

## Приоритет

Средний. Улучшает качество ревью, но не критично для работоспособности системы.
