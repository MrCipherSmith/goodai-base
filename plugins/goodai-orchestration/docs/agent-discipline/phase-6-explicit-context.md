# PRD: Phase 6 — Явное конструирование контекста для субагентов

## Цель

Задокументировать и внедрить принцип: субагент никогда не наследует контекст сессии оркестратора — оркестратор явно передаёт только то, что нужно.

## Проблема

Сейчас в скиллах оркестрации нет явных инструкций о том, что передавать субагентам. Оркестраторы могут:
- Передавать весь контекст сессии (дорого, шумно, засоряет контекст субагента)
- Не передавать ничего (субагент работает вслепую)
- Передавать случайный набор данных без структуры

## Решение

Каждый dispatch субагента должен содержать явно сконструированный контекст:

### Обязательные поля контекста субагента

```markdown
## Задача
[Конкретная задача — что именно сделать]

## Acceptance Criteria
[Список критериев — когда задача считается выполненной]

## Контекст
[Только релевантная информация — файлы, решения, ограничения]

## Файлы для чтения
[Конкретный список файлов которые нужно прочитать]

## Ограничения
[Что нельзя делать / какие файлы не трогать]
```

### Принципы конструирования

1. **Минимальность**: передавай только то, что нужно для этой конкретной задачи
2. **Явность**: лучше избыточно явно, чем неявно
3. **Изоляция**: субагент не должен делать предположений о состоянии сессии
4. **Конкретность**: пути к файлам, не "посмотри в директории skills"

## Скоп изменений

1. `skills/job-orchestrator/SKILL.md` — добавить шаблон dispatch сообщения
2. `skills/feature-dev/SKILL.md` — обновить инструкции диспатча субагентов
3. `skills/issue-analyzer/SKILL.md` — добавить шаблон для task-implementer dispatch
4. Создать `rules/core/subagent-context-construction.md` — правило для переиспользования

## Преимущества

- Снижение галлюцинаций субагентов (нет лишнего шумного контекста)
- Экономия контекстного окна оркестратора (субагент не тянет историю)
- Воспроизводимость (один и тот же dispatch = один и тот же результат)
- Отладка (легко понять что получил субагент)

## Acceptance Criteria

- [ ] `rules/core/subagent-context-construction.md` создан с шаблоном и принципами
- [ ] Все скиллы оркестрации содержат ссылку на правило или шаблон
- [ ] Шаблон достаточно конкретен чтобы агент не мог его "упростить"
- [ ] Добавлена Red Flag: "Субагент сам разберётся что ему нужно"

## Приоритет

Средний. Важно для масштабируемости оркестраций.
